## 💻 2. PASSO A PASSO NA SUA MÁQUINA NOVA (EM 3 COMANDOS)

Assim que você estiver na máquina nova com o Windows ligado:

### Passo 1: Pré-Requisitos Rápidos (Se Ainda Não Tiver)
1. Instale o **Git para Windows** (baixe em `git-scm.com` com instalação padrão).
2. Instale o **Node.js** (LTS) e o **Antigravity 2.0 / Antigravity IDE**.

---

### Passo 2: O Comando Mágico de Restauração (No PowerShell)
Abra o **PowerShell** na máquina nova e digite apenas estes 3 comandos:

```powershell
# 1. Clone o seu ecossistema oficial da nuvem:
git clone https://github.com/suporte-dash/ecossitema-agentes_google.git

# 2. Entre na pasta clonada:
cd ecossitema-agentes_google

# 3. Execute o restaurador automático em 1 clique:
powershell -ExecutionPolicy Bypass -File .\restore.ps1
```
