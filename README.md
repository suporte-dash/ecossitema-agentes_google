## 🚀 Como Restaurar em uma Máquina Nova (Bootstrap em 20 Segundos)

Ao instalar o Antigravity 2.0 e a IDE na sua nova máquina:

1. Abra o PowerShell ou terminal e clone este repositório:
   ```bash
   git clone https://github.com/suporte-dash/ecossitema-agentes_google.git
   ```
2. Entre na pasta e execute o restaurador automático:
   ```powershell
   cd ecossitema-agentes_google
   .\restore.ps1
   ```
3. **Pronto!** O script injetará automaticamente todas as **90 skills completas, regras P0 e a memória** na raiz do seu usuário (`C:\Users\<SeuUsuario>\.gemini\config\`).
Ao abrir a Antigravity IDE, todos os seus agentes já estarão 100% ativos e conscientes de todas as regras e conhecimentos!

## 🔄 Como Sincronizar Alterações Futuras (sync.ps1)

Sempre que criarmos ou evoluirmos qualquer skill, regra ou memória:

```powershell
.\sync.ps1
```
O script cuidará de copiar tudo e atualizar este repositório no GitHub automaticamente.
